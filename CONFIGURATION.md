# Configuration Aldetic

La configuration Supabase publique déjà présente dans `assets/js/config.js` est conservée. Ne jamais y ajouter de clé `service_role`, Groq ou Resend.

Pour les corrections, suivre exclusivement `DEPLOIEMENT-COMPLET.md` : migration SQL, déploiement des Edge Functions et secrets serveur.

Le mode téléphone `000000` est un mode de démonstration contrôlé côté serveur. Il ne contacte aucun opérateur et ne constitue pas une vérification réelle du numéro.
